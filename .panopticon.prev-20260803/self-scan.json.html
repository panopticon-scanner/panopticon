HIGH INJ-001 OS command injection via unsanitized shell script construction skill/scripts/run_fixture_tests.py:53 security / injection / POSSIBLE CONFIRMED agent:lens_sweep claude-haiku-4-5-20251001 partial
Description
check_fixtures builds a shell script by f-string interpolating manifest paths into 'if [ -d "{p}" ]...' and runs it via sh -c. Paths containing shell metacharacters execute as commands.
Impact
An attacker able to modify tests/fixtures/manifest.json executes arbitrary commands in the container context.
Remediation
shlex.quote() the paths, or drop the shell entirely and pass a list argv (e.g. ['test','-d',p]).
References
  • https://cwe.mitre.org/data/definitions/78.html
  • https://owasp.org/www-community/attacks/Command_Injection

tests/fixtures/manifest.json is PR-modifiable; a malicious entry achieves arbitrary command execution in the container a maintainer or CI spins up.
Remediation
Run one argv-list docker invocation per fixture (no shell), or shlex.quote every path.

Description
check_fixtures builds a shell script by f-string interpolating manifest paths into 'if [ -d "{p}" ]...' and runs it via sh -c. Paths containing shell metacharacters execute as commands.
Impact
An attacker able to modify tests/fixtures/manifest.json executes arbitrary commands in the container context.
Remediation
shlex.quote() the paths, or drop the shell entirely and pass a list argv (e.g. ['test','-d',p]).
